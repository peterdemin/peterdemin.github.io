# Rotating square cross-sections

`physics.mjs` wraps locally vendored Planck 1.5.1 in SI units. `main.mjs` renders
the actual oriented vertices and maps mouse/touch/keyboard requests to safe
spawns. `bundle.js` is generated by `scripts/build_rotating_boxes.py`; the
standalone page uses classic local scripts so it also works from `file://`.

The 0.35 m, 1 kg uniform squares have inertia 0.0204166667 kg m², zero starting
spin/velocity, friction 0.6, restitution 0.25, no damping, and bullet CCD.
The 4 × 3 m container is fixed. There is no box-count cap; occupied spawn
space is visibly refused. No existing body is deleted or teleported to fit.

Steps are 1/240 s with 12 velocity and 8 position iterations, warm starting,
polygon manifolds, and sleeping. Planck's defaults include 0.005 m slop,
0.01 m polygon skin, 1 m/s restitution threshold, 0.01 m/s and 2°/s sleep
thresholds, and a 0.5 s sleep time. These deliberately approximate rest;
numerical position correction is not exact energy conservation.

Run `node source/_static/rotating-boxes/checks.mjs` and
`python3 scripts/build_rotating_boxes.py --check` from the repository root.
The chapter is `01f-rotating-boxes.rst`, immediately after the two-ball demo.
